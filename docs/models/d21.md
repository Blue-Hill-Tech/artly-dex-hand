Tech, Inc. (DBA Artly). This repository provides engineering references, SDK

## Reported specifications

These values are **reported in the supplied documentation, not independently
measured**. Source **S** is a privately retained specification reference, p.1;
source **P** is a privately retained communication protocol. See the
[product review](../product-review.md) for source details. Exact shipped options
and test conditions require confirmation.

| Parameter | Reported value | Source |
| --- | --- | --- |
| Total / active degrees of freedom | 21 / 16 | S p.1 |
| Transmission | Linkage drive | S p.1 |
| Dimensions | 200 × 85 × 47 mm (L × W × D) | S p.1 |
| Bare hand mass | 815 g, excluding optional external sensors | S p.1 |
| Maximum fingertip force | 25 N | S p.1 |
| Maximum static whole-hand grasp load | 20 kg; not a dynamic payload rating | S p.1 |
| Minimum open-close cycle time | 0.8 s; load/test definition unverified | S p.1 |
| Repetitive positioning accuracy | ±0.2 mm; test method not provided | S p.1 |
| Motor | Coreless BLDC | S p.1 |
| Tactile sensing | 3D arrays on five fingertips | S p.1 |
| Minimum detectable force | ≤0.1 N; not an accuracy rating | S p.1 |
| Control modes | Position / force-position hybrid, as described in the specification | S p.1 |
| Control frequency / latency | 10 kHz / 0.2 ms; measurement boundaries unspecified | S p.1 |
| Host interfaces | RS485 / CAN FD | S p.1; P pp.3–6 |
| No-load grasp cycle life | ≥1.5 million cycles | S p.1 |
| Power | Rated 12 V; maximum 240 W / 20 A | [Electrical reference](../reference/zh/electrical-interface.pdf), p.1 figure |

The 10 kHz claim is not a measured host command or telemetry rate. The
protocol reference (P p.15) specifies 50 Hz
joint-position updates. The SDK exposes position and torque modes; a validated
force-position hybrid controller is not established by this delivery. See the
[document review](../product-review.md) for source details and discrepancies.

## Interfaces and software

The supplied Python README states Python 3.8+; the documented dependency pins
use Python 3.12.
See [setup](../setup.md#python-sdk) for the dependency-version distinction.
The supplied transport code implements
RS485 Modbus RTU and Modbus-framed CAN FD through CANable SLCAN. RS485 defaults
to 500000 baud, 8N1. The CAN FD code requests 1 Mbps arbitration and 2 Mbps data;
the current SLCAN configuration defect must be resolved before hardware use.

The ROS2 package targets Ubuntu 24.04 / ROS2 Jazzy according to its September 2,
2026 README. It provides 16-angle commands, gesture presets, position/torque
modes, fan control, tactile calibration and sensor topics. Its default launch
opens hardware and writes zero targets. Use `use_simulation:=true` for offline
work. `/joint_states` represents commanded targets, not measured feedback.

The reviewed controller manual lists Windows 10/11. The controller and its
manuals are not distributed in this repository; contact Artly for an approved
package. Read [setup](../setup.md) for SDK dependencies, entry points and hardware
preparation.

## CAD and simulation

Open [the hand STEP file](../../cad/d21-hand.stp) and
[RealMan adapter](../../cad/realman-adapter.stp) in a STEP-capable CAD application.
Use the mechanical drawings for the exact assembly revision before installation.
Screw lengths, mounting loads, clearance and fit remain to be confirmed.

Both hands are represented in [simulation](../../simulation). Models have
21 movable joints; the SDK accepts 16 independent angle commands and the example
scripts apply five distal-joint couplings. ROS2 and standalone model variants
are retained separately. Loading a model does not establish grasp performance,
contact behavior or accurate dynamics.
